# 🏦 Banking Management System

## 📌 Project Overview

A simple **Banking Management System** developed using Java. This project demonstrates basic banking operations through a console-based application and helps manage common banking activities in an organized way.

## 🛠️ Technologies Used

- Java
- Object-Oriented Programming (OOP)

## ✨ Main Features

- 👤 Customer account management
- 💰 Deposit money
- 💸 Withdraw money
- 💳 Check account balance
- 🏦 Basic banking operations
- 🖥️ Console-based user interface

## 📦 Dependencies

This project does not require any external libraries or frameworks.

It uses the standard Java Development Kit (JDK).

## 🚀 How to Run Locally

### Prerequisites

- Install Java JDK on your computer.
- Make sure Java is added to your system PATH.

### Steps

1. Clone the repository:

```bash
git clone https://github.com/kaziaurpon/Banking-Management-System.git
```

2. Navigate to the project folder:

```bash
cd Banking-Management-System
```

3. Compile the Java program:

```bash
javac Main.java
```

4. Run the program:

```bash
java Main
```
